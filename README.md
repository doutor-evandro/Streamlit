# Hello World em Streamlit

Meu primeiro app em Streamlit.

## Rodar localmente

```bash
pip install -r requirements.txt
streamlit run main.py
```

O app abre em http://localhost:8501

## Arquivos

- `main.py` — o app (funcao `main()` como ponto de entrada)
- `requirements.txt` — dependencias que o Streamlit Cloud instala no deploy
